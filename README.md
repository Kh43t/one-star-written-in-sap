A single one-line 1-star review written by a houseplant about its human owner, under 280 characters. The plant's grievance: its human went on holiday and left it with a neighbour who watered it with leftover espresso. It asked for rain, got caffeine, and is now jittery, acidic, and wide awake at 3am with no eyelids to close.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), exactly one line, 212 characters, no trailing newline. Deterministic: the same line on every run.
